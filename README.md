# Merak — نظام إدارة الفندق والسبا والمطعم

**Merak** نظام عربي بالكامل (RTL) لإدارة الفندق والسبا والمطعم، يعمل داخل المتصفح فقط، بدون قاعدة بيانات أو خادم أو أي API خارجي.
مبني بـ **React + TypeScript + Vite + Tailwind CSS + React Router + Lucide**، ويُخزَّن كل شيء في **localStorage**.

> ⚠️ **مهم عن التخزين:** البيانات تُحفظ داخل **هذا المتصفح وعلى هذا الجهاز فقط**.
> لا توجد مزامنة بين الأجهزة أو المتصفحات، وهي ليست قاعدة بيانات سحابية. مسح بيانات الموقع أو تغيير المتصفح/الجهاز
> أو التصفح الخاص قد يمحو السجلات. استخدم **تصدير نسخة احتياطية (JSON)** من «الإعدادات» بانتظام.
> التخزين المحلي غير مشفّر، فلا تحفظ فيه بيانات هوية حساسة على أجهزة مشتركة.

## تسجيل الدخول

* اسم المستخدم: `merak`
* كلمة المرور: `123456`

> هذا قفل بسيط للواجهة يمنع الاستخدام العابر فقط، **وليس حماية حقيقية**: التطبيق كله يعمل في المتصفح،
> وأي شخص يستطيع قراءة كود الصفحة أو تجاوزه. لا تُحفظ كلمة المرور في التخزين؛ يُحفظ فقط أن الجلسة مفتوحة
> (حتى إغلاق التبويب، أو على الجهاز إذا اخترت «تذكرني»). لتغيير البيانات عدّل `src/lib/auth.ts`.

## المزايا

| الوحدة | ما تقدمه |
| --- | --- |
| لوحة التحكم | إجمالي/متاحة/مشغولة/محجوزة، وصول ومغادرة اليوم، الحجوزات النشطة، الإيرادات والمصروفات والصافي والأرصدة المستحقة، أحدث الحجوزات، نظرة على الإشغال — كلها محسوبة من بياناتك |
| الغرف | إضافة/تعديل/عرض/حذف، منع تكرار الرقم، بحث وتصفية، حالات: متاحة، مشغولة، محجوزة، قيد التنظيف، تحت الصيانة |
| النزلاء | إضافة/تعديل/عرض/حذف، بحث بالاسم أو الهاتف أو رقم الهوية، سجل الحجوزات |
| الحجوزات | حساب الليالي والخصم والإجمالي والمتبقي لحظيًا، منع التعارض على نفس الغرفة، التحقق من التواريخ والسعة |
| الاستقبال | وصول/مغادرة اليوم، تسجيل الوصول والمغادرة، منع الانتقالات غير الصحيحة، تحويل الغرفة إلى «قيد التنظيف» بعد المغادرة |
| المدفوعات والفواتير | دفعات نقدًا/بطاقة/تحويل بنكي، سجل الدفعات، متابعة المتبقي، فاتورة قابلة للطباعة أو الحفظ PDF |
| السبا | قائمة خدمات (تصنيف، سعر، مدة)، حجز مواعيد بوقت ومعالج، إتمام الجلسة، إلغاء |
| المطعم | قائمة طعام بالتصنيفات، طلبات بالطاولة أو خدمة الغرف، كميات وخصم، تتبع «قيد التحضير / تم التقديم» |
| المصروفات | تصنيفات، بحث وتصفية بالتاريخ |
| التقارير | الإشغال والحجوزات والإيرادات والمصروفات، فلترة بالتاريخ، تصدير CSV وطباعة |
| الإعدادات | بيانات الفندق، **العملات وأسعار الصرف**، التفضيلات، النسخ الاحتياطي والاستعادة، حذف كل البيانات |

### السبا والمطعم: طريقتا المحاسبة

* **على حساب الغرفة:** يُضاف المبلغ إلى فاتورة الإقامة (يظهر بندًا في الفاتورة) بعملة الحجز، ويُسدَّد مع دفعات الحجز. يُحتسب ضمن الإيرادات عند السداد.
* **دفع مباشر (زائر / عميل خارجي):** يُحدَّد العميل والعملة وطريقة الدفع، ويُسجَّل إيرادًا عند «تحصيل وإغلاق».
* أسعار القائمة تُحفظ مع كل طلب، فتعديل سعر صنف لاحقًا لا يغيّر الطلبات السابقة.
* لا يمكن حذف طلب مكتمل، ولا إلغاء/حذف حجز عليه طلبات محمّلة غير ملغاة، ولا إلغاء طلب إذا أصبح المدفوع على الحجز أكبر من إجماليه.
* تقرير «السبا والمطعم» يعرض المبيعات حسب القسم والتصنيف والأكثر طلبًا.

### تعدد العملات

* فعّل أي عملة من القائمة (جنيه، ريال، درهم، دولار، يورو، دينار…) وحدّد **العملة الأساسية** وسعر صرف كل عملة مقابلها من «الإعدادات».
* أسعار الصرف تُدخل **يدويًا** (لا اتصال بالإنترنت لجلب الأسعار).
* كل غرفة وحجز بعملة، ويمكن **استلام الدفعة بعملة مختلفة** عن عملة الحجز؛ يُحوَّل المبلغ تلقائيًا ويُحتسب على رصيد الحجز.
* يُحفظ **سعر الصرف مع كل دفعة ومصروف** وقت تسجيله، فلا تتغير السجلات القديمة عند تعديل الأسعار لاحقًا.
* التقارير ولوحة التحكم تجمع بالعملة الأساسية وتعرض أيضًا المقبوضات لكل عملة.
* لا يمكن تغيير العملة الأساسية بعد تسجيل دفعات أو مصروفات، ولا حذف عملة مستخدمة في سجلات.

## التشغيل محليًا

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev        # خادم التطوير على http://localhost:5173
```

أوامر أخرى:

```bash
npm run build      # بناء الإنتاج داخل dist/
npm run preview    # معاينة نسخة الإنتاج محليًا
npm test           # اختبارات منطق الأعمال والتخزين (Node test runner عبر tsx)
npm run typecheck  # فحص أنواع TypeScript
```

## النشر على Vercel

1. ارفع المشروع إلى GitHub.
2. في Vercel اختر **Add New → Project** واستورد المستودع.
3. الإعدادات تُكتشف تلقائيًا (Framework: Vite، Build: `npm run build`، Output: `dist`) — الملف `vercel.json` يضبطها.
4. لا توجد متغيرات بيئة ولا أسرار مطلوبة.

ملف `vercel.json` يحتوي قاعدة إعادة كتابة تُوجّه كل المسارات إلى `index.html` حتى تعمل الروابط المباشرة مثل `/reservations` و`/invoices/...` بعد النشر أو عند تحديث الصفحة.

## هيكل المشروع

```
src/
  lib/            منطق الأعمال بدون React (قابل للاختبار)
    types.ts        أنواع البيانات
    actions.ts      كل عمليات الإضافة/التعديل/الحذف + التحقق (رسائل عربية)
    logic.ts        الحسابات: الليالي، الإجمالي، المتبقي، التعارض، حالة الغرفة، الانتقالات
    stats.ts / reports.ts   لوحة التحكم والتقارير
    storage.ts      خدمة localStorage الوحيدة (كل الوصول للتخزين من هنا)
    backup.ts       تصدير/استيراد JSON مع تحقق كامل
    currencies.ts   كتالوج العملات والتقريب
    csv.ts          تصدير CSV (مع حماية من حقن المعادلات)
  store/          DataContext (الحالة + الحفظ) و ToastContext
  components/     مكونات الواجهة المشتركة والنماذج
  pages/          صفحات التطبيق
  layout/         الهيكل العام والقائمة الجانبية
tests/            اختبارات الوحدة
```

## مفاتيح التخزين (localStorage)

كل المفاتيح تبدأ بـ `hms:v1:` (رقم الإصدار يسمح بترحيل البيانات مستقبلًا):

| المفتاح | المحتوى |
| --- | --- |
| `hms:v1:meta` | إصدار مخطط البيانات |
| `hms:v1:settings` | بيانات الفندق، العملات وأسعار الصرف، التفضيلات |
| `hms:v1:rooms` | الغرف |
| `hms:v1:guests` | النزلاء |
| `hms:v1:reservations` | الحجوزات |
| `hms:v1:payments` | الدفعات |
| `hms:v1:expenses` | المصروفات |
| `hms:v1:serviceItems` | خدمات السبا وأصناف المطعم |
| `hms:v1:orders` | مواعيد السبا وطلبات المطعم |
| `hms:v1:counters` | عدّادات أرقام الحجوزات والطلبات (لا يُعاد استخدام الأرقام) |
| `merak:session:v2` | علامة أن المستخدم سجّل الدخول (بدون كلمة المرور) |
| `hms:v1:corrupt:*` | نسخة من أي قيمة تالفة تعذّرت قراءتها، تُحفظ بدل حذفها بصمت |

سلوك التخزين: الكتابة كلها-أو-لا-شيء (عند امتلاء التخزين يُسترجع الوضع السابق وتظهر رسالة)،
قراءة JSON آمنة، تنبيه إذا كان التخزين غير متاح (يعمل التطبيق في الذاكرة لهذه الجلسة فقط)،
ومزامنة تلقائية بين تبويبات نفس المتصفح.

## قواعد الاتساق

* لا يمكن حذف غرفة أو نزيل مرتبط بحجوزات.
* لا يمكن حذف حجز عليه دفعات أو حجز منتهٍ (سجل تاريخي ومالي)؛ يمكن إلغاؤه.
* الدفعة لا تتجاوز المتبقي على الحجز، ولا تُسجَّل على حجز ملغي.
* لا يُسمح بحجزين نشطين متداخلين لنفس الغرفة (يُسمح بمغادرة ودخول في نفس اليوم).
* المغادرة تحوّل الغرفة إلى «قيد التنظيف» ولا يُسمح بتسكين نزيل في غرفة قيد التنظيف أو الصيانة.
* الاستيراد يتحقق من البنية والمراجع والعملات والتعارضات قبل أي استبدال، ويطلب تأكيدًا، ولا يغيّر البيانات الحالية إذا فشل التحقق.
